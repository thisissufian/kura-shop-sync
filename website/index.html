Multi-Device Synchronization

"Brave-Style" Multi-Phone Sync Chain

Pair Owner and Cashier phones in 2 seconds via QR code or a 12-word recovery mnemonic. Phones discover each other automatically over shop Wi-Fi (UDP port 42851) and stream encrypted deltas (TCP port 42850) with 0 cloud dependencies.

Data Integrity

Commutative CRDT Stock Ledger

Stock is derived strictly from immutable event deltas. Two cashiers selling the same item offline never overwrite counts.

Stock = Opening + ∑(Restocks) - ∑(Sales)
• Integer minor units (i64)
